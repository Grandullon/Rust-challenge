Primer uso (solo una vez)

Para cada base del panel inferior pulsa "Seleccionar". Cuando se abra el explorador navega hacia dentro hasta la ruta indicada y elígela ahí — no selecciones \\Alhambra\grupo$ directamente porque Windows lo bloquea. Una vez configuradas las bases, las próximas veces basta con abrir este archivo y se comprobará solo.

Importante: guarda este archivo en una ubicación fija (no en Descargas, no descargues copias nuevas con sufijos (1), (2)…) — si la ruta del archivo cambia, el navegador olvida los permisos y hay que volver a configurar.
